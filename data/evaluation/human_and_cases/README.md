# Published evaluation summaries

This directory contains summary results, parameter settings and analysis scripts. Individual evaluator scores and detailed per-case records are retained in the local research archive.

| Path | Public contents |
| --- | --- |
| `D8_weight_sensitivity/` | Stage II weight settings, aggregate results and scripts |
| `D10_geometry_prior_sensitivity/` | Parent-shape prior settings, 54-run aggregate results and scripts |
| `analyze_rating_agreement.py` | Ordinal agreement calculation script; requires individual ratings from the local archive |

The manuscript and Supplementary Information report the formal evaluation results. `reproduction/main_results.json` retains the compact numerical summary.
