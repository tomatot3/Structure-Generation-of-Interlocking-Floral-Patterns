# Manual correction comparisons

Open [preview.html](preview.html) to browse 25 before/after image pairs. Each PNG places the original structure on the left and the manually edited structure on the right. There are five examples for each of the five historical prototypes. `index.json` maps case IDs to images.

This folder contains comparison images only. Detailed geometric records, editor sessions and per-case generation parameters are maintained separately in the local research archive. These images accompany the retained and supplementary correction records; adding them does not change the released generation parameters or experimental results.
