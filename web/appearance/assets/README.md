# Application motifs

`sea-dragon.png` is the generated blue-and-white texture from the ceramic design case, reused here for its central sea-and-dragon motif. The application samples only its central motif; the surrounding floral border is always rendered from the current project SVG. It is not a photograph of a historical object.

`sea-dragon-wrap.png` recomposes that generated motif as a rectangular sea-and-dragon field for the full circumference of bowls and cups. The circular source remains in use for plate centres.
