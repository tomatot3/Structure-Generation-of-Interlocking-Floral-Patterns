# Repository data layout

Repository: https://github.com/tomatot3/Structure-Generation-of-Interlocking-Floral-Patterns

Git tracks the code, procedural prototypes, parameter settings, source-annotation vectors without embedded source images, evaluation records, website source and documentation. The complete generated structure and rendering collection and the 108-context comparison archive are retained locally by the project team.

The local ZIP archives are stored outside the Git repository. When running commands that need an archived case or paired image, extract the corresponding archive into the repository root. The downloaded folders are excluded by `.gitignore`.
