构成分析的重点来源

以下内容对应当前补充表S22，图件位置和参考文献号与当前正文一致。

来源对象图版出处与图像形式构成观察及用途
莫高窟第392窟卷草边饰陈茹茹[3]，第8页表1.2第二行。出版描图，原表注明采自《敦煌图案集》。波状走势与仰俯交替母题。与铜镜、金银器纹饰比较主要走势及母题位置（图2a）。
铜镜、金银器纹饰（依原图注）陈振旺[26]，第136页图3-71。出版描绘图。相邻母题沿波状枝蔓排列，花叶外形与第392窟不同。用于比较连续走势与交替组织（图2a）。
莫高窟第335窟藻井边饰陈振旺[26]，第149页表4-3、第147页表4-2。出版描图，原表注明王一茗绘制。到达花位的弯曲路径与短卷枝并存，用于区分承花路径与普通分枝（图2b）。
古阳洞南壁第一排东起第四小龛平台边饰范祎珂[23]，第28、59页，附录4条目C2-3。作者自绘图。七叶忍冬母题围绕主藤交替回旋，作为SW1-C布局的参照（图1、图3）。
古阳洞法生造像龛平台边饰范祎珂[23]，第59页，附录4条目C2-2。作者自绘图。与南壁龛台图样比较不同叶形下的交替回旋组织（图3a）。
魏晋织物植物纹样（依原图注）张红颖[2]，第23页图3-12左图，转引《中国传统艺术》第59页。出版图录图。主要枝蔓、局部回卷及引向叶形的细枝，作为主枝与侧枝关系的参照（图2c）。
清雍正黄色地缠枝牡丹纹织金锦，故宫博物院藏梁科[28]，第87页。藏品照片及局部。由花外可见枝段推定花内接续，作为SW2构成解释的代表（图3b）。
莫高窟第16窟甬道缠枝西番莲纹样敦煌研究院[27]，图片“甬道—缠枝西番莲纹样”。壁画照片。侧枝连接相邻花位，遮挡处按枝段走势推定。用于SW3及双花关系比较（图3c、图S2）。
莫高窟第217窟卷草边饰陈茹茹[3]，第9页表1.3第二行。出版描图，原表注明采自《敦煌图案集》。左侧花团由短枝连接，主藤从下方继续延伸。与第16窟比较侧枝承花（图3c）。
彩绘瓷罐花枝边饰Jones[29]，图版LXXII顶部，说明见第14页。历史装饰图录绘图。花头、花间枝叶与重复组织共同支持连续路径的解释，作为SW2比较来源（图3b）。

完整记录与SVG路径见 `source_materials/index.json` 和 `source_materials/annotations.csv`。Jones图版LXXII标注由作者补充，雍正织金锦和莫高窟第16窟标注由既有图3矢量解释导出。它们与原有118份标注合为121份。
