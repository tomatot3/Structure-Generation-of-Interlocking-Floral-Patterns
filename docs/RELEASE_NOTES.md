# Package notes

Package organization updated: 26 September 2026.

The package contains the core structural generator and its runtime geometry checks, editable source annotations, generated structures, paired renderings, correction examples and the interactive website. Recorded seeds, controls and asset correspondences support regeneration and reuse.

The data ZIP contains the generated assets and accompanying documentation. Its data dictionary and asset summary match the repository's public scope.

Author/citation metadata and licenses remain to be supplied separately.
